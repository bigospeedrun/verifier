BOARD STATEMENT vs PAPER'S OWN CLAIM.json  (the model-comparison object)

1. WHAT THE BOARD BOUNDS (site text, read 2026-11-07)

  Problem  Polynomial multiplication over F2
  Input    two polynomials over F2, each given as its n coefficient bits
  Output   the 2n-1 coefficient bits of their product in F2[x]
  Note     "Coefficients add without carries, so this is a different problem
            from integer multiplication."
  Machine  "The machine is a deterministic Turing machine with a fixed number
            of tapes and a fixed alphabet. Its running time counts every step,
            including reading the input and writing the output."
  Quantity "The quantity is kappa in a worst-case running time of
            O(n log^{1-kappa} n). A higher kappa is better."
  Baseline O(n log n 4^{log* n}) (Harvey-van der Hoeven 2019)
  Caveat   "Harvey and van der Hoeven (2022) reach O(n log n) only if an
            unproved hypothesis on primes in arithmetic progressions holds."

  So the tracked quantity is a log-exponent kappa of a Turing-machine running
  time -- NOT bilinear complexity, NOT algebraic complexity, NOT a circuit
  size. Any audit of this row must stay inside that model.

4. VERDICT ON THE MODEL COMPARISON

  Field-by-field, the two descriptions are the same problem, the same machine
  and the same cost measure: deterministic, one machine for every n, fixed
  finite alphabet, fixed finite number of one-dimensional tapes, every
  transition counted including input and output, all 2n-1 coefficients
  emitted, kappa = 1 - (log exponent), higher kappa stronger.

  Two places where a row could silently weaken have been checked and do not:

  (a) Output convention.  The board wants all 2n-1 bits.  Theorem 1 returns
      "the first 2n-1 returned cyclic coefficients [which] are exactly the
      ordinary product", with zeros emitted (CLAIM.json output says
      "including zeros").  main.tex:110-116 also charges input copying, head
      returns and erasure.  No hidden output convention.

  (b) Machine weakening.  O(n log^{1-kappa} n) is a Turing-machine statement,
      so a bit-cost bound on a word-RAM with an unbounded word would not
      transfer.  The paper states the fixed-alphabet/fixed-tape constraint in
      the theorem itself (main.tex:100-105) and its cost ledger charges tape
      movement per bit (COST_LEDGER.txt "All masks remain present", 
      "Every private crop occurs at its proved completed boundary").  The
      bound is stated on the board's machine, and the paper's own CLAIM.json
      asserts the identity.  This audit did not re-derive the tape-movement
      simulation; see README "Honest limits".

  Note on direction of the two rows.  Larger kappa is better, so
  1301/1302 (exponent of log = 0.9992319...) is strictly stronger than
  1-2^-38 (exponent 0.99999999999636...).  The improvement is
  1/1302 / 2^-38 = 2.1112e8 in kappa.  It is NOT a different problem and NOT
  a different machine.
